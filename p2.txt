Step 1 – Start Minikube
minikube start

Check nodes:
kubectl get nodes

Step 2 – Create a Docker image
If you have a Dockerfile:
docker build -t myapp:v1 .

Check the image:
docker images

Step 3 – Make the image available to Minikube
If the image is built locally:
minikube image load myapp:v1

This loads your Docker image into Minikube.
Step 4 – Deploy the image in Kubernetes
kubectl create deployment myapp --image=myapp:v1 --image-pull-policy=IfNotPresent

Here:
- myapp = Deployment name.
- --image=myapp:v1 = Docker image.
- IfNotPresent = Use the locally available image if it is already present.
Step 5 – Check deployment
kubectl get deployments

kubectl get pods

Step 6 – Check detailed information
kubectl describe deployment myapp

kubectl logs deployment/myapp

Step 7 – Expose the application
If your application runs on port 3000:
kubectl expose deployment myapp --type=NodePort --port=3000

Step 8 – Access the application
minikube service myapp

This opens the application in your browser.
Step 9 – Delete the deployment
kubectl delete service myapp
kubectl delete deployment myapp
