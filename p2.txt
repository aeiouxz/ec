Create an Android application that copies an image from one ImageView to another when the Copy Image button is pressed and restores the original state when the Restore button is pressed.

Widgets:

ImageView 1 — displays the original image
ImageView 2 — initially empty
Copy Image button
Restore button
TextView — displays the current status

When Copy is clicked, copy the image and display "Image Copied Successfully". When Restore is clicked, remove the image from ImageView 2 and display "Image Restored to Initial State".

MainActivity.java
package com.example.adarsh3;

import android.os.Bundle;
import android.widget.Button;
import android.widget.ImageView;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    ImageView img1, img2;
    Button btnCopy, btnRestore;
    TextView tvStatus;

    @Override
    public void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        img1 = findViewById(R.id.img1);
        img2 = findViewById(R.id.img2);

        btnCopy = findViewById(R.id.btnCopy);
        btnRestore = findViewById(R.id.btnRestore);

        tvStatus = findViewById(R.id.tvStatus);

        // Copy image
        btnCopy.setOnClickListener(v -> {

            // Get image from img1 and put it in img2
            img2.setImageDrawable(img1.getDrawable());

            tvStatus.setText("Image Copied Successfully");
        });

        // Restore image
        btnRestore.setOnClickListener(v -> {

            // Remove image from img2
            img2.setImageDrawable(null);

            tvStatus.setText("Image Restored to Initial State");
        });
    }
}
