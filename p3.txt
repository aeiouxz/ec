Create an Android application that implements a Text Counter using two Buttons and two TextViews.

TextViews

TextView 1 — displays the current counter value
TextView 2 — acts as Reset

Buttons

+ — Increment
− — Decrement

The initial counter value should be 0. The + button increases the value by 1, the − button decreases it by 1, and clicking the Reset TextView resets the counter to 0.

MainActivity.java
package com.example.adarsh3;

import android.os.Bundle;
import android.widget.Button;
import android.widget.TextView;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    TextView tvCount, tvReset;
    Button btnPlus, btnMinus;

    // Counter variable
    int count = 0;

    @Override
    public void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        tvCount = findViewById(R.id.tvCount);
        tvReset = findViewById(R.id.tvReset);

        btnPlus = findViewById(R.id.btnPlus);
        btnMinus = findViewById(R.id.btnMinus);

        tvCount.setText("0");
        tvReset.setText("Reset");

        // Increment
        btnPlus.setOnClickListener(v -> {

            count++;

            tvCount.setText(String.valueOf(count));
        });

        // Decrement
        btnMinus.setOnClickListener(v -> {

            count--;

            tvCount.setText(String.valueOf(count));
        });

        // Reset
        tvReset.setOnClickListener(v -> {

            count = 0;

            tvCount.setText("0");
        });
    }
}
