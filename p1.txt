# Experiment 12 – Install kubectl and Start Minikube on Windows
### 1. Download kubectl
```
curl.exe -LO "https://dl.k8s.io/release/v1.37.0/bin/windows/amd64/kubectl.exe"
```
### 2. Verify kubectl installation
```
kubectl version --client
```
Detailed version:
```
kubectl version --client --output=yaml
```
### 3. Create Minikube directory
Run PowerShell as Administrator.
```
New-Item -Path 'C:\' -Name 'minikube' -ItemType Directory -Force
```
### 4. Download Minikube
```
$ProgressPreference = 'SilentlyContinue'
Invoke-WebRequest -OutFile 'C:\minikube\minikube.exe' -Uri 'https://github.com/kubernetes/minikube/releases/latest/download/minikube-windows-amd64.exe' -UseBasicParsing
```
### 5. Add Minikube to PATH
```
$oldPath = [Environment]::GetEnvironmentVariable('Path', [EnvironmentVariableTarget]::Machine)

if ($oldPath.Split(';') -inotcontains 'C:\minikube') {
    [Environment]::SetEnvironmentVariable('Path', "$oldPath;C:\minikube", [EnvironmentVariableTarget]::Machine)
}
```
Close and reopen PowerShell.

### 6. Verify Minikube installation
```
minikube version
```
## 7. Start Minikube cluster
```
minikube start
```
### 8. Check cluster status
``
minikube status
```
### 9. Interact with Kubernetes cluster
```
kubectl get nodes
```
```
kubectl get pods -A
```
Alternative using Minikube:
```
minikube kubectl -- get pods -A
```
### 10. Launch Kubernetes Dashboard
```
minikube dashboard
```
### 11. Additional useful commands (Added)
Stop Minikube:
```
minikube stop
```
Delete Minikube cluster:
```
minikube delete
```
Restart Minikube:
```
minikube start
```
View cluster information:
```
kubectl cluster-info
```
View all nodes:
```
kubectl get nodes -o wide
```
View pods in current namespace:
```
kubectl get pods
```
View all namespaces:
``
kubectl get namespaces
```
Describe a node:
```
kubectl describe nodes
```
